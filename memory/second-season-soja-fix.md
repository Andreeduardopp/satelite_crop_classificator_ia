Second-season SOJA (sown Jan–Feb) is systematically predicted as MILHO at high confidence; main-season (Nov–Dec) SOJA is fine. Built `src/model/train_xgboost_v6.py` to attack it (A/B/C/E plan). Validated with a season-stratified out-of-fold diagnostic (random CV HIDES this — global SOJA recall is ~0.94 while 2nd-season recall is ~0.18).

**Root cause is DATA SCARCITY, not the date shortcut.** Training set has only **28 second-season SOJA (all January, ZERO in Feb–Mar)** vs ~563 MILHO in Jan–Mar (Feb alone = 384 safrinha). Key experiment: **date-feature ablation (A) does NOT help** — dropping planting_doy/sin/cos left 2nd-season recall unchanged at 0.179 and tanked everything else (overall acc 0.883→0.837, main-season SOJA 0.970→0.804, SOJA→MILHO 18→73). So those 28 fields look like MILHO *spectrally*; removing dates is a net loss — do NOT ship date_mode=none.

**The fix that worked (`--preset fix`):** date_mode=cyclic + class-balance + **6× up-weight on 2nd-season SOJA** (B) + C3-legume-vs-C4-grass red-edge/senescence features (C, uses NDRE/CIRE/PSRI/NDMI from [[red-edge-indices-added]]) + abstain gate (E). Result: 2nd-season SOJA recall **0.179→0.321** (nearly 2×), main-season preserved (0.972), overall metrics unchanged (0.883/0.898). Abstain gate: max-softmax-prob threshold, e.g. t=0.75 → 86% coverage / 93.4% covered acc; t=0.90 → 73% / 96.9%. Saved to `abstain_policy.json`; inference should emit NAO_CLASSIFICAVEL below threshold.

**Honest limit & next steps:** 28 samples (0 in Feb–Mar) can't fully teach the signature — recall is still only 0.32. Durable fix = **collect Feb–Mar SOJA training data**. **UPDATE 2026-06-20: data collected.** Ran `phenology_feature_pipeline_v5 --mode full` on `src/data/aug_ss_soja_febmar` (103 fields). DB now has **103 Feb–Mar SOJA (was 0)** and **176 second-season (Jan–Mar) SOJA** total. Optical is healthy on the new fields (1–6% null/stage after interpolation). BUT before celebrating any recall jump, see [[sar-coverage-gap-safrinha]] — SAR is mostly missing for these fields and its missingness is a spurious season proxy. **Retrained (`--preset fix --trials 0`): 2nd-season SOJA recall 0.321 → 0.895**, main-season preserved (0.975), 2nd-season SOJA→MILHO down to 7. **A/B-tested the SAR-shortcut fear and it's clean** — recall is 0.901 even with SAR fully dropped, so the gain is the real augmentation, not the missingness artifact. Augmentation WORKED. Results above are `--trials 0` (default params); a full Optuna run (`--trials 120`) is ~hours because tuning uses weighted manual CV (5 fits/trial). v6 also fixes a v5 bug: it excludes `optical_backfill_done` and `interpolated_stages` from features.

**HELD-OUT TEST CONFIRMS THE FIX (2026-06-22).** Rewrote `src/model/evaluate_test.py` to use the v5 pipeline + v6 functions (was importing v4 modules), with the season diagnostic + abstain policy applied to test. Re-extracted the test set with v5 pipeline into `src/data/features_test_v5/` (366 fields: 50/crop + all 16 held-out safrinha SOJA; the old `features_test/features.db` was v4-era with no red-edge cols and was unusable for v6). Evaluated run `runs_v6/20260620_055235_aug_febmar`: **overall acc 87.6%, macro-F1 0.875** (matches train OOF 0.881/0.895 — small overfit gap). **The win: 2nd-season SOJA recall on truly-unseen fields = 0.938 (15/16), and SOJA→MILHO = 0 (zero, incl. 0 safrinha).** The original failure (safrinha→MILHO, recall 0.321) is GONE on held-out data. Abstain t=0.80: 75% coverage / 96% covered acc; of 16 safrinha, 6 abstained and the 10 covered were all correct. **Caveats:** (1) n=16 safrinha is tiny — 0.938 is 15/16, wide CI, one field flipping moves it ~6pp. (2) Cost of the safrinha up-weight shows elsewhere: MILHO F1 dropped most (0.932→0.872, recall 0.82) with MILHO→SOJA=3 — the expected precision/recall trade, acceptable but watch it. (3) AVEIA/TRIGO still the weak pair ([[aveia-trigo-bottleneck]]), unchanged. Leaked field `SOJA_517392809-1` was confirmed absent from the final test DB (excluded 0).

**TUNING DOESN'T HELP — SHIP THE DEFAULT-PARAMS MODEL (2026-06-22).** Ran `--trials 40` (`runs_v6/20260622_071428_aug_febmar_tuned`); it LOST to the `--trials 0` default model on every metric: acc 0.876 vs 0.882, macro-F1 0.890 vs 0.895, **2nd-season SOJA recall 0.866 vs 0.895**, SOJA→MILHO 16 vs 11 (2nd-season 9 vs 7). Root cause: the Optuna objective is global weighted macro-F1, NOT 2nd-season recall, so tuning optimizes the wrong target; 40 trials didn't even match the hand-set defaults (n_est=500/depth=6/lr=0.05). Tuned best was lr=0.103 (more aggressive → slightly worse generalization). Don't bother re-running with more trials unless the Optuna objective is changed to weight 2nd-season recall. **The model to ship is `runs_v6/20260620_055235_aug_febmar` (`--trials 0`)**, validated on held-out test (safrinha recall 0.938, 0 SOJA→MILHO).

**LARGER HELD-OUT TEST CONFIRMS IT (2026-06-25).** Re-ran eval on ~200/crop (1,414 fields, SOJA 216 incl. all 16 safrinha; `features_test_v5`): **acc 0.910, macro-F1 0.910** (HIGHER than train OOF 0.895 — not overfit; positive test−train per-class deltas on 6/7 crops). **2nd-season SOJA recall 0.938 (15/16), SOJA→MILHO=2 both main-season, ZERO safrinha→MILHO.** Abstain t=0.80: 83% coverage / 96.8% covered acc; of 16 safrinha 6 abstained, 10 covered all correct. Per-class F1: ARROZ .99, CAFE .98, SOJA .96, FEIJAO .95, MILHO .94, AVEIA .79, TRIGO .76. **Safrinha n is permanently capped at 16** — the test split holds only 17 second-season SOJA total (1 excluded as leak), so a bigger extraction can't tighten that CI; would need new safrinha KMLs. Full results in `src/model/SECOND_SEASON_SOJA_RESULTS.md`.
