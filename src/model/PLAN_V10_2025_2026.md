# Plan v10 — recent-years model (2025/2026) + the 350-KML 2026 test set

**Date:** 2026-07-09 · **Decision:** the next model trains **only on 2025/2026 data** (the most
recent), as balanced as possible across the 7 crops, and is judged on a **new 350-KML test set
(50/crop) from the 2026 crop year** — sampled and frozen today by `scripts/sample_kml_test_2026.py`
into `src/data/kml_test_2026/` (seed 42, manifest with field_ids alongside).

**Trade-off accepted up front:** dropping 2024 means this model does NOT target the TRIGO-2024
collapse on the old 250-KML benchmark (`FIELD_TEST_5CROP_ANALYSIS_AND_PLAN.md`). The bet is
forward-looking: production traffic from now on is 2026/27-season fields, so recency > backfill.
The bench250 stays reported for reference, but the new 2026 test becomes the promotion gate.

## 3. Balanced 2025/2026 training composition (v10)

Start from the merged pool (`features_v8v9_train`, 22,727 rows), **drop the 789 plantio-2024 rows**
(750 CAFE + 27 SOJA + 12 misc) → 21,938 rows, all 2025/2026. Then balance to a **2,500/crop cap**
(cap chosen = TRIGO's total supply; AVEIA is the hard floor at 1,623):

| Crop | Have (25/26) | v10 target | Action |
|---|--:|--:|---|
| SOJA | 4,939 | 2,500 | subsample, stratified by cohort — keep **all 1,176 safrinha** |
| MILHO | 4,500 | 2,500 | subsample, keep the ~1,500 safrinha share |
| FEIJAO | 3,613 | 2,500 | subsample, stratified by planting month |
| ARROZ | 3,241 | 2,500 | subsample (keep the 6 plantio-2026) |
| TRIGO | 2,501 | 2,501 | keep all (100% winter-2025 — refreshed in Dec) |
| CAFE | 1,533 | 2,500 | **extract ~970 new** (free plantio ago–out/25 pool: 26k) |
| AVEIA | 1,623 | 1,623 | keep all — no free supply until Dec |
| **Total** | 21,938 | **~16,624** | imbalance 1.54× (was 3.1×), class-balance weights absorb the rest |

Stratified subsampling = preserve each crop's cohort mix (safrinha / main / spring / summer) and
keep every plantio-2026 row (truncated-tail summer cohorts — the year-diversity signal).
Safrinha up-weight: **1×** (ssw sweep showed data made the weight unnecessary; higher weights
only grow MILHO→SOJA).

**New extraction bill (now):** ~970 CAFE train + 250 test = **~1,220 fields ≈ 4,900 Stats-API
requests** (well under one day; v9 did 16.5k in ~21 h).

## 4. Execution order

1. **[DONE]** Sample + freeze `kml_test_2026` (350 KMLs, manifest, exclusions).
2. Extract the 250 extractable test fields → `src/data/features_test_2026/features.db`.
3. Extract ~970 CAFE (plantio 2025-08-01..2025-10-05, excluding the 50 test CAFE) → append pool.
4. Build `src/data/features_v10_train/features.db`: merged pool − 2024 rows − any test/bench id,
   capped per §3 (write a `build_v10_train.py` with seed + manifest of dropped/kept ids).
5. Train the ladder with `train_xgboost_v7.py --soja-ss-weight 1` (5-crop first; 6/7-crop after
   CAFE lands). Evaluate every run on: **(a) features_test_2026** (the new gate), (b) the old
   v8 held-out (n=973/1373 — regression check vs 0.986), (c) bench250 via `eval_bench250.py`
   (reference only; TRIGO-2024 expected to stay weak — accepted trade-off).
6. **Promotion bar** on the new 2026 test: ≥0.95 covered accuracy at ≥0.85 coverage with the
   abstain threshold calibrated on the *benchmark* sweep (0.90 region), not the OOF no-op 0.30.
7. **December 2026 batch:** extract the frozen TRIGO/AVEIA test 100 (full season) + ~1,100 AVEIA
   and ~2,000 TRIGO winter-2026 training fields → retrain v11 with two-winter TRIGO/AVEIA and a
   complete 7-crop 2026 test. This also finally gives TRIGO its second year — the structural fix
   the bench250 collapse pointed at.

  guard before `predict_proba`.**

## 6. Risks / open points

- **ARROZ test is 2025/26-season (plantio out/25–fev/26), not plantio-2026** — no such rice
  exists free with a complete cycle. Fine for a recency gate; revisit with the 2026/27 rice
  season (~mar/27).
- **FEIJAO test pool was thin (426 free)** — the 50 sampled are valid, but regional spread was
  not enforced (filenames carry no coordinates; enforce at extraction review if needed).
- **TRIGO/AVEIA stay single-winter (2025) until December** — the v10 model's TRIGO is as
  year-brittle as v9's; the new test only measures it against 2026 winter in December. Do not
  promote a TRIGO-sensitive deployment before that eval.
- **CAFE train/test both skew plantio ago–out/25** — same-season train and test for CAFE; its
  test number reads as in-distribution, not year-generalization. Acceptable (perennial), note it
  in the model card.
